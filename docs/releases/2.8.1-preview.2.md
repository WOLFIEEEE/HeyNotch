# HeyNotch 2.8.1 Preview 2

A focused bugfix preview for unwanted notch opening and unstable notch motion reported after Preview 1. App and XPC version **2.8.1**, build **273**, replace the **2.8.0 (272)** identity. This release remains an independent, GPL-3.0 personal fork.

## Fixed

- The closed notch’s hover and file-drag opening area follows its visible bounds. An invisible 640 × 210 area below the closed notch no longer accepts an opening drag.
- Delayed hover and file-drag requests check the pointer again before opening, so moving away cancels an obsolete open request.
- The hosting window keeps stable bounds while the visible notch opens and closes, avoiding clipping caused by resizing the window during the transition.
- Notch motion has one animation owner. Interactive gestures track directly, and Reduce Motion avoids the animated transition instead of layering competing animations.
- Only the selected tab supplies a matched-geometry source, removing competing hidden sources from the moving highlight.
- The music visualizer resumes changes from its currently displayed bar heights, avoids a forced 24-frame-per-second animation cadence, and shows a static presentation with Reduce Motion.

## Verification scope

The integrated app test suite passed 275 tests with no failures or skipped tests, including 13 drag-policy and 8 interaction-geometry cases. Native visualizer checks covered 44 assertions plus the existing animation-lifecycle checks. Release packaging has separate fixture tests; signing, notarization, and downloaded installation require their own evidence for the final artifact.

No new live cursor/file-drag session, WindowServer click-through check, or measured frame-rate validation was available for this patch. Automated policy, geometry, and animation checks do not establish those visible interaction results.

## Preview limits

This maintenance release addresses notch interaction and motion. It does not close the existing real two-sided call, native notification/Focus delivery, live paid-provider request, or wider microphone/insertion/device acceptance gaps. Native task movement menus were verified previously; automated pointer dragging did not establish native task drag-and-drop acceptance.

The universal app contains Apple silicon and Intel code and targets macOS 14 or later. Intel and macOS 14 runtime acceptance remain incomplete. Automatic microphone-app attribution requires macOS 14.2+, and the bundled Now Playing adapter requires macOS 15+; direct music-app integrations remain available on macOS 14.

Automatic updates remain disabled. Local speech models download separately. Meeting recording begins only when you choose Start and grant the relevant macOS permissions. Optional provider processing uses your own provider account and may incur charges. Agent access remains opt-in with explicit list scopes.

## Install and update

Use **`HeyNotch-2.8.1-273-notarized.zip`** attached to this release and follow the included `INSTALL.md`. To update from Preview 1, stop recording, save any needed transcript, quit HeyNotch, and replace the copy in Applications before reopening it. Do not disable Gatekeeper or remove quarantine to bypass failed verification.

The app ZIP includes GPL-3.0 licensing, third-party notices, `SOURCE_STATE.json`, and a `READ-ME.txt` link to its exact corresponding source. Download **`HeyNotch-2.8.1-273-source.tar.gz`** separately from this same release. The source archive, matching `SOURCE_STATE.json`, and `SHA256SUMS.txt` accompany the app with the same download access. The release tag **`v2.8.1-preview.2`** must identify the reviewed source commit used for this candidate.

Signing, Apple notarization and downloaded-artifact verification apply to this exact build. Preview 1’s interactive installation check does not establish a new interactive test for Preview 2. Consult the release publication record for the completed distribution checks; the new live interaction checks listed above remain open.
