# HeyNotch 2.8.2 Preview 3

This maintenance preview fixes thirteen task, Shelf, navigation, and processing issues identified in the UX audit of Preview 2. App and XPC version **2.8.2**, build **274**, replace the **2.8.1 (273)** identity. HeyNotch remains an independent, GPL-3.0 personal fork.

## Fixed

1. **Unsaved task drafts stay protected.** Add, Edit, voice-task proposals, and meeting passages use the same Keep current / Replace draft confirmation. Keep current is the default, and replacement is blocked during saving or if the draft changed while the confirmation was open.
2. **Cancel no longer implies it can reverse a committed task save.** It is disabled until saving and its follow-up refresh finish; the underlying action also rejects cancellation during that interval.
3. **Undo clears when its reminder has already been removed elsewhere.** Only a successful, current fetch of all reminders can remove the obsolete action. Failed or stale fetches preserve it, as does moving the reminder to another list.
4. **Task summaries follow the selected list immediately.** The footer derives its list name and open-task count from current data while keeping operation messages separate.
5. **Hidden tabs no longer create a navigation dead end.** When Always show tabs is off and the Shelf is empty, Music retains a compact page menu that can return to Tasks and other enabled pages.
6. **The shortcut timer respects the battery popover.** Delayed closing uses one shared rule that also protects pointer presence, menus, sharing, and active drop targets. Explicit Close actions remain available.
7. **Shelf Copy preserves the original contents.** Links retain their URL scheme, text retains its whitespace, and mixed selections include files, links, and text in their appropriate clipboard representations.
8. **Shelf Share respects the whole selection.** Sharing a selected text item includes the other selected items. Acting on an unselected item uses that item rather than an unrelated selection.
9. **Shelf cleanup preserves newer changes.** Validation removes only still-invalid entries from the current collection instead of replacing it with an older snapshot, protecting items added or updated while validation runs.
10. **Leaving Processing keeps cancelled work cancelled.** A delayed key read cannot restart verification after the pane's task or operation has been cancelled.
11. **Processing cancellation shows an accurate status.** Cancelling verification or a model test replaces its progress message instead of leaving Verifying or Testing visible after work stops.
12. **Voice review no longer offers an ineffective cleanup retry.** Retry cleanup follows the same availability rule as its handler and remains unavailable after an insertion attempt, preserving the safeguard against repeated insertion.
13. **Preparing an installed speech model avoids a false disk-space failure.** Existing files are verified before checking download capacity; only missing or invalid files require download space, plus the existing headroom allowance. Actual model-loading errors remain separate.

## Verification scope

Regression tests exercise draft replacement and save races, authoritative Undo cleanup, list summaries, asynchronous Shelf cleanup and mixed transfer payloads, processing cancellation, speech-model file verification, voice review policy, and notch navigation/automatic-close policy. Tests use synthetic tasks, controlled asynchronous operations, local fixture files, fake keys and HTTP, and isolated clipboard data where applicable; they do not require real Reminders data, provider accounts, or a live call.

Final integrated test counts, the reviewed source commit, and distribution evidence for this candidate are recorded in `docs/RELEASE_READINESS.md`. Release packaging separately checks that previous version/build identities cannot reach notarization and that release notes and source are taken from the frozen candidate snapshot.

No new installed-app cursor/drag session, rendered menu or popover session, live cross-app clipboard/share workflow, accessibility navigation check, or frame-rate measurement is established by these automated tests. The low-disk fixture checks file-store behavior; it does not establish CoreML loading under actual disk exhaustion. Developer ID signing, Apple notarization, and downloaded-artifact verification apply to the exact final artifact and are separate from the regression tests.

## Preview limits

This release does not close the existing real two-sided call, native notification/Focus delivery, live paid-provider request, or wider microphone/insertion/device acceptance gaps. Native task movement menus were verified previously; automated pointer dragging did not establish native task drag-and-drop acceptance.

The universal app contains Apple silicon and Intel code and targets macOS 14 or later. Intel and macOS 14 runtime acceptance remain incomplete. Automatic microphone-app attribution requires macOS 14.2+, and the bundled Now Playing adapter requires macOS 15+; direct music-app integrations remain available on macOS 14.

Automatic updates remain disabled. Local speech models download separately. Meeting recording begins only when you choose Start and grant the relevant macOS permissions. Optional provider processing uses your own provider account and may incur charges. Agent access remains opt-in with explicit list scopes.

## Install and update

Use **`HeyNotch-2.8.2-274-notarized.zip`** from the matching published release and follow the included `INSTALL.md`. To update from an earlier preview, stop recording, save any needed transcript, quit HeyNotch, and replace the copy in Applications before reopening it. Do not disable Gatekeeper or remove quarantine to bypass failed verification.

The app ZIP includes GPL-3.0 licensing, third-party notices, `SOURCE_STATE.json`, and a `READ-ME.txt` link to its exact corresponding source. Download **`HeyNotch-2.8.2-274-source.tar.gz`** separately from the same release. The source archive, matching `SOURCE_STATE.json`, and `SHA256SUMS.txt` accompany the app with the same download access. The release tag **`v2.8.2-preview.3`** must identify the reviewed source commit used for this candidate. A candidate ZIP is not a published installer, and previous previews' distribution checks do not establish acceptance of this new artifact.
