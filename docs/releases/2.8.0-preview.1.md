# HeyNotch 2.8.0 Preview 1

A preview of the independent HeyNotch fork, with a task-first notch, local voice tools, meeting transcripts, and scoped task access for MCP clients. This release uses app version **2.8.0**, build **272**, and the approved blue H-notch identity.

## Included

- A resizable To do / Doing / Done board backed by a selected Apple Reminders list. Doing stays on this Mac; completion syncs through Reminders.
- Local Whisper dictation, reviewed voice-task drafts, and cross-app text insertion with focus and clipboard safeguards.
- Separate Claude, OpenAI, and OpenRouter settings, Keychain-stored keys, and exact model selection for optional text processing.
- Call activity reminders, an explicit Start action, separate microphone/call-audio capture paths, local transcription, export, and optional text-only meeting history.
- A native local MCP helper with nine task tools, per-client list scopes, optional writes, revocable access, and guarded retry handling. Connection export uses a private, atomic save.
- The existing music, shelf, battery, calendar, and notch controls, plus measured reductions in redundant idle updates and animation timers.

## Preview limits

This is a prerelease, not a claim that every macOS/app/device combination is certified. Real two-sided calls, notification delivery under Focus, live paid provider requests, and the wider microphone/insertion matrix still need acceptance coverage. Native task movement menus were verified; automated pointer dragging did not establish native drag-and-drop acceptance.

The universal app contains Apple Silicon and Intel code and targets macOS 14 or later. Intel and macOS 14 runtime acceptance remain incomplete. Automatic microphone-app attribution requires macOS 14.2+, and the bundled Now Playing adapter requires macOS 15+; direct music-app integrations remain available on macOS 14.

Automatic updates are disabled. Install subsequent previews manually. Local speech models download separately, and meeting capture requests the relevant macOS permissions only when you choose Start. Provider processing may incur charges on your own account. MCP access starts disabled and does not expose provider keys or meeting recordings.

## Install and source

Use the notarized ZIP attached to this release and follow the accompanying `INSTALL.md` release asset. Move HeyNotch.app into Applications before setting up permissions. Do not disable Gatekeeper or remove quarantine to bypass a failed verification.

The app ZIP includes GPL-3.0 licensing, third-party notices, `SOURCE_STATE.json`, and a `READ-ME.txt` link to its exact corresponding source. Download **`HeyNotch-2.8.0-272-source.tar.gz`** separately from this same release; it is not nested inside the app ZIP. The source archive, matching `SOURCE_STATE.json`, and `SHA256SUMS.txt` are attached alongside the app with the same download access. The release tag must identify the reviewed source commit used for the candidate.
