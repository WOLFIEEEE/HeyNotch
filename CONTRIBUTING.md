# Contributing to HeyNotch

HeyNotch is a personal fork of [Boring Notch](https://github.com/TheBoredTeam/boring.notch).

- Work happens only in `WOLFIEEEE/boring.notch---Personalizaton`.
- **Never open pull requests, issues or pushes against `TheBoredTeam/boring.notch`.**
- When creating a PR, always target this fork explicitly:

```bash
gh pr create --repo WOLFIEEEE/boring.notch---Personalizaton
```

See [CLAUDE.md](CLAUDE.md) for the full rules.
